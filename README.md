# 龍井智慧防汛平台

臺中市龍井區雨水下水道淹水預報與應變平台（服務建議書展示原型）。

**網址**：https://willy110611-collab.github.io/longjing-flood/

- 各里未來 18 小時積水預報（AI 替代模型，以 120 組 SWMM 模擬訓練；參數取自臺中市龍井區雨水下水道系統檢討規劃報告）
- 即時資料：中央氣象署雨量、潮汐預報、特報（民生公共物聯網、中繼站），水利署烏溪大肚橋水位，臺中市水利局淹水感測器
- 主管、承辦人員、里長、一般民眾四種身分

預報為示意成果，正式水理成果以 SWMM 模型為準。

資料來源：中央氣象署、經濟部水利署、臺中市政府水利局、內政部國土測繪中心、內政部消防署。
